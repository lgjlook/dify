## 屏蔽前端对 /console/api/system-features 的请求（写死模拟值）

- 目标：前端不再请求 `http://localhost:5001/console/api/system-features`，最小化改动。
- 新增 `web/features/system-features/mock.ts`：静态 `SYSTEM_FEATURES_MOCK: GetSystemFeaturesResponse`（COMMUNITY 默认值，形状对齐 test fixture `baseSystemFeatures`），从 `@dify/contracts` 导入类型与 zod 枚举，无 `'use client'`/`'server-only'` 指令（供两侧安全引用）。
- 改 `web/features/system-features/client.ts`：`systemFeaturesQueryOptions` 改为返回静态 `queryOptions({ queryKey: ['system-features'], queryFn: () => SYSTEM_FEATURES_MOCK })`，不再走 `consoleQuery.systemFeatures.get`。
- 改 `web/features/system-features/server.ts`：`systemFeaturesServerQueryOptions` 同样改为静态 mock（覆盖 `getSystemFeatures`/`getOptionalSystemFeatures`/`dehydrateSystemFeatures` 服务端预取）。
- 注意：`/console/api/system-features/license` 端点（license-badge）未动，属不同接口。
- 两个生产调用点（client.ts、server.ts）是仅有的发起该 HTTP 请求处；其余 `consoleQuery.systemFeatures.*` 命中均为测试文件，未改。

- 用户选择「删请求层+空桩」：删掉真正的后端请求、hook 改为返回空数据/disabled，组件继续编译、不再发 HTTP。
