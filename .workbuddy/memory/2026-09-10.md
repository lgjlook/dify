## 移除 Console 登录（feature/simple-main 分支）

按用户要求「去掉登录功能 /signin，直接访问首页」，采用**完整免登录 + 硬改（无 env 开关）**方案。

改动清单：

- `api/extensions/ext_login.py`：新增 `_load_default_console_account()`；console/inner_api blueprint 无 access token 时不再 raise Unauthorized，改为自动加载「第一个 active 且 role=owner、租户 normal 的账号」（按 created_at 升序；无 owner 时退化到任意 active 账号），并置 `g._login_bypassed = True`。
- `api/libs/token.py`：`check_csrf_token()` 开头若 `g._login_bypassed` 为真则直接 return（否则没有登录 cookie，所有写操作会 401 "CSRF token is missing or invalid"）。
- `web/service/base.ts`：删除 `buildSigninUrlWithRedirect()`（及其 `OAUTH_AUTHORIZE_PATH`/`SIGNIN_PATH`/`resolveLoginRedirectTarget` 依赖）；401 分支不再跳转登录页，改为直接 reject + toast。
- `web/service/fetch.ts`：`already_setup` 403 改跳 `/`。
- `web/app/signin/layout.tsx`：改为 server component 直接 `redirect('/')`，覆盖 /signin、/signin/check-code、/signin/invite-settings。
- `web/app/auth/refresh/route.ts`：refresh 失败改跳首页（`createHomeRedirectResponse`）。
- 删除 `web/app/signin/__tests__/layout.spec.tsx`；`web/service/__tests__/base.spec.ts` 移除 signin 相关用例。

保留说明：`app/signin/` 目录未整体删除，因为 `_header.tsx`、`split.tsx`、`utils/post-login-redirect.ts` 被 signup / webapp-reset-password / oauth authorize / device 复用。

验证：web `tsc --noEmit` 通过；`vitest run --project unit service/__tests__/base.spec.ts` 6 passed；后端 `py_compile` + SQL 构造验证通过。（eslint 因 devEngines 要求 node 24 跑不起来，未执行。）
